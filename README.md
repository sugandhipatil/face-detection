# Face Detection and Emotion Recognition

This project uses Python, OpenCV, and DeepFace to detect faces and recognize facial emotions using a webcam.

## Features

- Real-time webcam detection
- Face detection
- Emotion recognition
- Displays the detected emotion on the screen

## Technologies Used

- Python
- OpenCV
- DeepFace
